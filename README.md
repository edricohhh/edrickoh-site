# Edric Koh Photography — website

Everything in this folder is the live website. Upload the **contents** of this
folder to GitHub (not the folder itself).

- `index.html` — the site
- `support.js` — required by index.html
- `content.json` — all the editable text
- `photos/photos.json` — which photos appear where
- `photos/sizes.json` — image dimensions (generated; leave alone)
- `photos/opt/` — the web-sized photos
- `admin/` — your admin page

Full-resolution originals are kept separately, outside this folder. They're
your masters — back them up somewhere, but they don't belong on the website.

Setup instructions: see ADMIN-SETUP.md in the chat.
